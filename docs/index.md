## Cómo recorrer el blog

1. Selecciona una **práctica** en el menú.
2. Consulta sus objetivos y responsabilidades.
3. Abre el **apartado** que te interese.
4. Utiliza el índice del documento para localizar cada paso.
5. Consulta las evidencias y el estado de revisión.

Las nuevas prácticas aparecerán en la navegación al incorporar sus
documentos.
